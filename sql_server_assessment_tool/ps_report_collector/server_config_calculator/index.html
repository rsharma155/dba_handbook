Built-in application rules (summary)

OLTP / Transactional

Higher IOPS & HADR bias. Moderate MAXDOP-style CPU; RAM for buffer cache.

E-commerce

Size for peaks; stronger network weight; premium SSD; high HADR.

SaaS / Multi-tenant

RAM & connection pooling matter; growth-oriented storage; high HADR.

Reporting / Analytics

CPU/RAM/storage heavy; throughput SSD; medium HADR (often async).

Mixed OLTP + Reporting

Balanced uplift across resources; prefer read replica for reports.

IoT / Telemetry

Ingest + storage growth dominate; partition/retention planning essential.

CMS / Content

Often smaller DB tier if CDN/cache offload media; medium HADR.

Batch / ETL

CPU + throughput disk for job windows; HADR can be lower if restartable.
